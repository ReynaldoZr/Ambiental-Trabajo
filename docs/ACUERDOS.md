# Acuerdos del grupo

## Versión 0.1

**Objetivo.** Demostrar que un estudiante puede reportar un problema ambiental y consultar qué hizo mantenimiento. El reto de la semana muestra cómo una campaña puede motivar a visitar la plataforma.

| Tema | Acuerdo para la demostración |
| --- | --- |
| Nombre | JaguarVerde, como en la propuesta de la asignatura. EcoReport U fue la referencia de requisitos de reportes. |
| Alcance | Tres pantallas web, siete categorías, foto obligatoria, tres estados y una observación por caso. |
| Datos | Una base local SQLite, con las fotos dentro de los registros. Se usan datos ficticios. |
| Roles | Vistas de estudiante y mantenimiento abiertas en el mismo equipo. Las cuentas y permisos se definirían antes de un piloto con usuarios reales. |
| Reto | «Cuidemos el agua», tres preguntas y diez puntos simbólicos por acierto. Un intento guardado por instalación y por reto. |
| Impacto | Mostrar el conteo real de casos resueltos en esa instalación. Una estimación de agua o energía ahorrada requeriría datos y un método acordado. |
| Evento y beneficios | El cierre de campaña entre facultades es una propuesta de piloto. Vida Estudiantil tendría que aprobar cualquier reconocimiento o registro de horas. |
| Entrega | Demo local desde IntelliJ o su terminal. El código se comparte en GitHub. |

Etapa futura: para usarlo con estudiantes reales, acordar primero con quién revisa los reportes, quién actualiza la campaña y cuándo se comunica una respuesta. Luego definir cuentas y permisos, almacenamiento y publicación. Si se incorporan puntos por reportes, la propuesta original los vincula a casos verificados y resueltos. Decidir su funcionamiento en una issue aparte.

## Cómo acordar un cambio

Anotar la fecha, la fuente o el enlace a la issue, qué cambia, por qué y quién lo acordó. Indicar qué parte de la demostración afecta y dejar las ideas que puedan esperar en una tarea aparte. Para la entrega académica, seguir la consigna de la profesora. La propuesta JaguarVerde, los requisitos de EcoReport U y las conversaciones del equipo sirven de referencia para ajustar el alcance.
